# Architecture decision records

ADRs record significant decisions, their context and consequences. Add a new
numbered record rather than rewriting the history of an accepted decision; link
superseding decisions where appropriate.

## Index

| ADR | Status | Decision |
| --- | --- | --- |

## Template

Copy this structure into a new numbered ADR:

```markdown
# ADR NNNN: Title

- **Status:** Proposed | Accepted | Superseded

## Context

What problem and constraints motivate the decision?

## Decision

What is being decided, and what is explicitly out of scope?

## Consequences

What benefits, trade-offs and follow-up work result?
```
